# Animated Gallery Prototype (Le Ciel '24)

Frontend UI prototype built with HTML, CSS, and JavaScript demonstrating directional slide-in image transitions (`slide-from-top`, `slide-from-left`) and asymmetric grid layout for the Le Ciel '24 gallery page.

## Files

- `index.html` - Two-tier gallery layout (2-card top grid with info sidebar + 4-card bottom strip)
- `style.css` - Flexbox/grid rules and keyframe slide animations
- `script.js` - Scroll and interaction handlers
- `image1.jpg` to `image6.jpg` - Sample gallery artwork

## Usage

Open `index.html` directly in a web browser.
